# Expert inspectors and the power plan editor

> Generated by `tools\Build-Docs.ps1` from `data\power\processor.json` and `data\inspectors\kernel.json`. Do not edit by hand.

Read-only inspectors (GUI page *Expert Inspectors*, `-Inspect All|Power|Interrupts|Network|Kernel|Timer|Crash`) show the settings engineers tune next to the Windows default. Only the processor power settings below can be edited here, with a snapshot first (`-PowerSetting <alias> -Ac <n> [-Dc <n>] -AcknowledgeRisk`, `-DryRun` to validate); everything else changes only through catalog items.

## Power plan editor

- Values are checked against the range `powercfg /qh` reports for the active plan.
- Hardware overlays apply: on Intel hybrid CPUs core parking and hybrid scheduling settings are blocked; on AMD dual-CCD X3D CPUs core parking is blocked; on laptops battery (DC) values are blocked.
- Processor idle disable is never editable (see `rejected.processor-idle-disable`).
- Defaults come from Windows' stored plan defaults; a plan copy is compared with the built-in plan it came from; Ultimate Performance has no stored defaults, so Balanced is shown as a labelled reference.

## Kernel and memory inspector
 value under these keys is listed; documented ones show their meaning and Windows default. Values linked to a catalog item can be changed only through that item; values linked to a rejected entry are explained and never changed.

### Session Manager\kernel

`HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\kernel`

Settings read by the kernel at boot. Most values here are set by Windows itself; the timer-resolution value is the only one iG Windows Tuner catalogues.

| Value | Windows default | Meaning | Link |
|---|---|---|---|
| `GlobalTimerResolutionRequests` | not set | 1 restores the pre-2004 behaviour where one process's timer-resolution request affects the whole system. | `sched.global-timer-resolution` |
| `ObCaseInsensitive` | 1 | Object names are case-insensitive. 0 is only for POSIX subsystems and breaks normal Windows path handling. |  |
| `DisableTsx` | not set | Intel TSX control used by speculative-execution mitigations. iG Windows Tuner never changes mitigation settings. | `rejected.spectre-mitigations-off` |
| `MitigationOptions` | not set | System-wide exploit protection settings written by Windows Security or Set-ProcessMitigation -System. Change them only through exploit protection. | `sec.exploit-protection-defaults` |
| `MitigationAuditOptions` | not set | Audit-mode counterpart of MitigationOptions (exploit protection). | `sec.exploit-protection-defaults` |

### Session Manager\Memory Management

`HKLM:\SYSTEM\CurrentControlSet\Control\Session Manager\Memory Management`

The memory manager sizes pools and caches dynamically on 64-bit Windows. The page file configuration is the only value iG Windows Tuner changes here (system-managed page file); the classic 'memory tweaks' are explained and rejected.

| Value | Windows default | Meaning | Link |
|---|---|---|---|
| `PagingFiles` | ?:\pagefile.sys | Page file configuration. '?:\pagefile.sys' means a system-managed page file; 'C:\pagefile.sys 4096 8192' a fixed size; an empty list no page file. | `system.pagefile-auto` |
| `ClearPageFileAtShutdown` | 0 | 1 overwrites the page file at shutdown (security policy 'Shutdown: Clear virtual memory pagefile'); shutdowns get slower. |  |
| `DisablePagingExecutive` | 0 | 1 keeps kernel-mode code and drivers in RAM. No measurable benefit with enough memory. | `rejected.disable-paging-executive` |
| `LargeSystemCache` | 0 | 1 favours the file cache over programs, a server setting that hurts desktop responsiveness. | `rejected.large-system-cache` |
| `FeatureSettingsOverride` | not set | Overrides speculative-execution mitigations. Set by tools that turn mitigations off. | `rejected.spectre-mitigations-off` |
| `FeatureSettingsOverrideMask` | not set | Mask that goes with FeatureSettingsOverride. | `rejected.spectre-mitigations-off` |
| `SecondLevelDataCache` | 0 | Legacy L2 cache size hint from the Windows NT era. Modern Windows reads cache sizes from the CPU and ignores tuning here. |  |
| `NonPagedPoolSize` | 0 | 0 lets Windows size the non-paged pool dynamically (64-bit Windows does this well). |  |
| `PagedPoolSize` | 0 | 0 lets Windows size the paged pool dynamically. |  |
| `SystemPages` | 0 | 0 lets Windows size system page table entries dynamically. |  |
| `SessionPoolSize` | 4 | Session pool size in MB, a Windows default. |  |
| `SessionViewSize` | 48 | Session view space in MB, a Windows default. |  |

### PriorityControl

`HKLM:\SYSTEM\CurrentControlSet\Control\PriorityControl`

Win32PrioritySeparation controls quantum length and the foreground boost. Windows' client default already favours the foreground window.

| Value | Windows default | Meaning | Link |
|---|---|---|---|
| `Win32PrioritySeparation` | 2 | Quantum length and foreground boost. 2 is the client default (short, variable quanta with foreground boost). | `rejected.win32-priority-separation` |
| `IRQ8Priority` | not set | A Windows 9x-era myth; Windows NT ignores IRQ priority values here. | `rejected.irq-priority` |
| `ConvertibleSlateMode` | 0 | Tablet/laptop posture reported by convertible devices. Not a tuning value. |  |

### Multimedia\SystemProfile (MMCSS)

`HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile`

MMCSS reserves CPU time for low-priority work while multimedia threads run and throttles non-multimedia network processing during playback. Values below 10 or above 100 are clamped to 20 by Windows.

| Value | Windows default | Meaning | Link |
|---|---|---|---|
| `SystemResponsiveness` | 20 | Percentage of CPU guaranteed to low-priority work. Rounded down to tens; below 10 or above 100 is clamped to 20; 100 disables MMCSS. | `sched.system-responsiveness` |
| `NetworkThrottlingIndex` | 10 | Limits non-multimedia network packet processing while MMCSS multimedia playback runs. 0xFFFFFFFF disables the throttling. | `sched.network-throttling-off` |
| `NoLazyMode` | not set | Undocumented community value. Not read by current Windows as far as Microsoft documents. |  |

`HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile\Tasks\Games`

Only applies to threads that call the MMCSS API for the Games task; most games do not. Microsoft documents GPU Priority and SFIO Priority as unused, so the popular edits have no effect.

| Value | Windows default | Meaning | Link |
|---|---|---|---|
| `Affinity` | 0 | Processor affinity bitmask; 0 means no affinity. | `rejected.mmcss-games-task` |
| `Background Only` | False | Whether the task has no user interface. | `rejected.mmcss-games-task` |
| `Clock Rate` | 10000 | Scheduling granularity hint (100 ns units); no guarantee since Windows 7. | `rejected.mmcss-games-task` |
| `GPU Priority` | 8 | Documented by Microsoft as not used. | `rejected.mmcss-games-task` |
| `Priority` | 2 | Task priority 1 (low) to 8 (high). | `rejected.mmcss-games-task` |
| `Scheduling Category` | Medium | High, Medium or Low scheduling category. | `rejected.mmcss-games-task` |
| `SFIO Priority` | Normal | Documented by Microsoft as not used. | `rejected.mmcss-games-task` |

### CrashControl

`HKLM:\SYSTEM\CurrentControlSet\Control\CrashControl`

Startup and recovery settings: the dump type, where dumps go, and whether Windows restarts automatically. Changes take effect after a restart.

| Value | Windows default | Meaning | Link |
|---|---|---|---|
| `CrashDumpEnabled` | 7 | 0 none, 1 complete, 2 kernel, 3 small (minidump), 7 automatic memory dump. | `system.dump-small` |
| `AutoReboot` | 1 | 1 restarts automatically after a blue screen; 0 keeps the stop screen up. |  |
| `DumpFile` | %SystemRoot%\MEMORY.DMP | Path of the kernel, complete or automatic memory dump. |  |
| `MinidumpDir` | %SystemRoot%\Minidump | Folder for small memory dumps. |  |
| `Overwrite` | 1 | 1 overwrites an existing memory dump file. |  |
| `LogEvent` | 1 | 1 writes an event to the System log after a stop error. |  |

## Other inspectors

- **Interrupts:** PCI devices with supported interrupt types (line, MSI, MSI-X), the mode in use (from the allocated interrupt resources), MSISupported / MessageNumberLimit, affinity policy, priority and target CPUs. Changes only through `gfx.gpu-msi` (GPU, Expert, reboot); manual affinity pinning is rejected.
- **Network queues:** RSS state, base and max processor, queues, receive and transmit buffers with the driver's range, and discarded-packet counters; advice is based on that evidence.
- **Timer:** GlobalTimerResolutionRequests behaviour (catalog item `sched.global-timer-resolution`). The current timer resolution is not shown because reading it needs an undocumented native call; `powercfg /energy` (administrator) lists timer requests.
- **Crash and page file:** dump type, dump files on disk, stop screen and verbose status settings, page file configuration and usage, with the System catalog items that change them.
