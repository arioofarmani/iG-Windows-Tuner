## BCD timer tweaks (useplatformclock, useplatformtick, disabledynamictick, tscsyncpolicy)

- **Claim:** Forces HPET/TSC behavior for lower input latency.
- **Category:** unstable
- **Reason:** No consistent measured gain on modern TSC-invariant CPUs; forcing the platform clock often increases timer overhead. Any BCD change can trigger BitLocker recovery, and iG Windows Tuner never runs bcdedit.
- **Sources:** <https://learn.microsoft.com/en-us/windows-hardware/drivers/devtest/bcdedit--set> <https://learn.microsoft.com/en-us/windows/security/operating-system-security/data-protection/bitlocker/recovery-overview>

## Disabling HPET in Device Manager or BIOS

- **Claim:** Removes timer latency.
- **Category:** placebo
- **Reason:** Windows already prefers the invariant TSC; disabling the HPET device changes nothing measurable or breaks software that needs it.

## Disabling VBS / Memory integrity in a preset

- **Claim:** A few percent more FPS.
- **Category:** anti-cheat-hostile
- **Reason:** FACEIT Anti-Cheat and Riot Vanguard On-Demand require VBS/HVCI, and it removes kernel exploit protection. Available only as the warned expert toggle sec.vbs-hvci-off-expert, never in a preset.
- **Sources:** <https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity>

## Disabling Spectre/Meltdown mitigations (FeatureSettingsOverride)

- **Claim:** Restores lost CPU performance.
- **Category:** security-reducing
- **Reason:** Removes protection against speculative-execution attacks reachable from browsers and games; gains on Raptor Lake are negligible for games.
- **Sources:** <https://support.microsoft.com/en-us/topic/kb4073119-windows-client-guidance-for-it-pros-to-protect-against-silicon-based-microarchitectural-and-speculative-execution-side-channel-vulnerabilities-35820a8a-ae13-1299-88cc-357f104f5b11>

## Win32PrioritySeparation edits

- **Claim:** Gives the foreground game more CPU quantum.
- **Category:** placebo
- **Reason:** The default (programs) already boosts the foreground; arbitrary hex values from guides change quantum lengths in ways that were never measured to help and can hurt background audio/voice.

## Disabling the page file

- **Claim:** Avoids disk paging.
- **Category:** unstable
- **Reason:** Games and drivers reserve commit charge; without a page file, commit can run out with RAM still free, causing crashes. No crash dumps either.
- **Sources:** <https://learn.microsoft.com/en-us/troubleshoot/windows-client/performance/how-to-determine-the-appropriate-page-file-size-for-64-bit-versions-of-windows>

## Disabling memory compression (32 GB RAM)

- **Claim:** Saves CPU time.
- **Category:** placebo
- **Reason:** With 32 GB RAM compression rarely runs during play; disabling it only increases paging under pressure.

## LargeSystemCache = 1

- **Claim:** Faster file access.
- **Category:** obsolete
- **Reason:** A server-era switch that favors the file cache over application working sets; harmful for games.

## DisablePagingExecutive = 1

- **Claim:** Keeps the kernel in RAM.
- **Category:** obsolete
- **Reason:** No measurable effect on modern systems with ample RAM.

## Disabling Fullscreen Optimizations globally

- **Claim:** Restores true exclusive fullscreen.
- **Category:** obsolete
- **Reason:** Modern flip-model presentation gives exclusive-fullscreen latency in borderless windows; disabling FSO globally can break VRR, Auto HDR and the Game Bar. Per-game compatibility settings remain available in Windows.
- **Sources:** <https://support.microsoft.com/en-us/topic/3f006843-2c7e-4ed0-9a5e-f9389e535952>

## MouseDataQueueSize / KeyboardDataQueueSize

- **Claim:** Lower input latency.
- **Category:** placebo
- **Reason:** Buffer sizes for the legacy class drivers; a smaller queue does not deliver input sooner, it only risks dropped input.

## IRQ priority registry keys (IRQ8Priority etc.)

- **Claim:** Prioritizes the timer or GPU interrupt.
- **Category:** placebo
- **Reason:** These values are not read by the modern Windows kernel or APIC-based interrupt routing.

## SvcHostSplitThresholdInKB

- **Claim:** Fewer svchost processes, less overhead.
- **Category:** security-reducing
- **Reason:** Merging services into shared hosts saves trivial memory with 32 GB and removes the isolation and reliability benefit of split service hosts.

## Power Throttling off on hybrid CPUs

- **Claim:** Prevents throttling of the game.
- **Category:** placebo
- **Reason:** Power Throttling targets background processes; turning it off lets background work compete for P-cores. iG Windows Tuner instead offers power.power-throttling-on to repair this tweak.
- **Sources:** <https://learn.microsoft.com/en-us/windows/win32/procthread/quality-of-service>

## E-core disabling, global affinity masks, Thread Director / heterogeneous policy overrides, core parking edits, OS C-state changes

- **Claim:** Keeps the game on P-cores.
- **Category:** unstable
- **Reason:** Thread Director and the Windows scheduler already place foreground threads on P-cores; overriding them removes headroom for background work and can cause stutter. C-states belong to BIOS.

## Legacy TCP/IP parameters (TcpWindowSize, Tcp1323Opts, DefaultTTL, MaxUserPort, MTU changes)

- **Claim:** Faster or lower-latency networking.
- **Category:** obsolete
- **Reason:** Ignored or superseded by receive-window auto-tuning since Windows Vista; wrong MTU values cause fragmentation and drops.
- **Sources:** <https://learn.microsoft.com/en-us/windows-server/networking/technologies/network-subsystem/net-sub-performance-tuning-nics>

## TCP auto-tuning disabled

- **Claim:** Lower ping.
- **Category:** placebo
- **Reason:** Does not reduce game (UDP) latency and caps TCP throughput on fast links. iG Windows Tuner repairs it to Normal instead.
- **Sources:** <https://learn.microsoft.com/en-us/powershell/module/nettcpip/set-nettcpsetting>

## TCPNoDelay interface registry value

- **Claim:** Disables Nagle's algorithm system-wide.
- **Category:** placebo
- **Reason:** Windows TCP does not read this per-interface value; Nagle is a per-socket option (TCP_NODELAY) set by the game. The related TcpAckFrequency setting is offered as net.delayed-ack-off.
- **Sources:** <https://learn.microsoft.com/en-us/windows/win32/winsock/ipproto-tcp-socket-options>

## MMCSS 'Games' task profile (GPU Priority 8, Priority 6, Scheduling Category High, SFIO High)

- **Claim:** Higher priority for game threads.
- **Category:** placebo
- **Reason:** Microsoft documents GPU Priority as 'not yet used', SFIO Priority as 'not used', and Priority as always treated as 2 when Scheduling Category is High. Only threads that register with the MMCSS 'Games' task are affected at all, which few games do.
- **Sources:** <https://learn.microsoft.com/en-us/windows/win32/procthread/multimedia-class-scheduler-service>

## NoAutoRebootWithLoggedOnUsers

- **Claim:** Windows Update never restarts while you are signed in.
- **Category:** obsolete
- **Reason:** Microsoft states the policy does not work exactly as described, applies only with AUOptions = 4, and can prevent quality-update reboots entirely. iG Windows Tuner uses the documented active-hours policy instead (privacy.update-active-hours).
- **Sources:** <https://learn.microsoft.com/en-us/windows/deployment/update/waas-restart>

## TurnOffWindowsCopilot policy

- **Claim:** Removes Copilot.
- **Category:** obsolete
- **Reason:** Deprecated by Microsoft and not applicable to the current Microsoft Copilot app; RemoveMicrosoftCopilotApp is not supported on Pro. Uninstall the app from Settings instead.
- **Sources:** <https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-windowsai>

## System-wide Mandatory ASLR (force randomization for images)

- **Claim:** Extra exploit protection.
- **Category:** unstable
- **Reason:** Forcing relocation of images that were not built for it breaks some games, launchers and anti-cheat components. Per-app exploit protection remains available in Windows Security.
- **Sources:** <https://learn.microsoft.com/en-us/defender-endpoint/exploit-protection-reference>

## Defender exclusions for game folders

- **Claim:** Faster loading.
- **Category:** security-reducing
- **Reason:** Creates a blind spot that malware (including cheat loaders) uses; real-time scanning cost on NVMe is small. iG Windows Tuner never adds exclusions.
- **Sources:** <https://learn.microsoft.com/en-us/defender-endpoint/common-exclusion-mistakes-microsoft-defender-antivirus>

## Disabling Defender, Windows Update, Firewall, UAC, DEP or SmartScreen

- **Claim:** Less background overhead.
- **Category:** security-reducing
- **Reason:** Large security loss for negligible performance gain; several kernel anti-cheats and game stores also rely on these components.

## Feature-flag overrides (ViVeTool, FeatureManagement overrides, native NVMe driver hacks)

- **Claim:** Unlocks hidden performance features.
- **Category:** unstable
- **Reason:** Unsupported, change between builds without notice, and can leave the system in states Microsoft never tested.

## Removing inbox components with DISM

- **Claim:** Debloats Windows.
- **Category:** unstable
- **Reason:** Not reversible from inside Windows, breaks servicing and cumulative updates, and some removed components are dependencies of games or anti-cheat.

## Standby-list cleaners and timer-resolution services

- **Claim:** Fixes stutter.
- **Category:** placebo
- **Reason:** Windows manages the standby list; purging it discards useful cache. Background services that hold timer resolution raise power use for everyone and need persistence that iG Windows Tuner deliberately avoids.

## Writing NVIDIA driver profiles (Profile Inspector style)

- **Claim:** Forces low-latency driver settings.
- **Category:** unstable
- **Reason:** Undocumented driver database edits; iG Windows Tuner only shows a read-only checklist for NVIDIA Control Panel and in-game Reflex.

## Hypervisor launch type off (bcdedit /set hypervisorlaunchtype off)

- **Claim:** Removes virtualization overhead for more FPS.
- **Category:** anti-cheat-hostile
- **Reason:** Turns off VBS, memory integrity, Windows Hello Enhanced Sign-in Security, WSL2, Windows Sandbox and Hyper-V, and FACEIT and Riot Vanguard On-Demand refuse to run. It is a BCD change, which iG Windows Tuner never makes (BitLocker recovery risk). The warned VBS/HVCI expert toggle covers the measurable part without touching BCD.
- **Sources:** <https://learn.microsoft.com/en-us/windows/security/hardware-security/enable-virtualization-based-protection-of-code-integrity>

## Processor idle disable (IDLEDISABLE power setting)

- **Claim:** Removes C-state wake-up latency.
- **Category:** unstable
- **Reason:** Keeps every core at active voltage and clock all the time: much more heat and power for a latency gain that is not measurable in games on current CPUs. On 13th and 14th gen Intel desktop CPUs it adds to the conditions behind Vmin Shift instability. The power plan editor never offers it and the Raptor Lake overlay blocks it.
- **Sources:** <https://www.intel.com/content/www/us/en/support/articles/000102331/processors.html>

## Pinning device interrupts to specific cores (AssignmentSetOverride)

- **Claim:** Moves GPU or NIC interrupts off busy cores for lower latency.
- **Category:** unstable
- **Reason:** Overrides Windows' interrupt steering with a fixed core mask that does not follow hybrid P-core/E-core scheduling, core parking or driver updates; a bad mask can starve a device. The interrupt inspector shows the current policy and target CPUs read-only.
- **Sources:** <https://learn.microsoft.com/en-us/windows-hardware/drivers/kernel/interrupt-affinity-and-priority>

## Test signing, nointegritychecks, kernel debugging or driver signature enforcement off

- **Claim:** Lets you load unsigned tuning drivers.
- **Category:** anti-cheat-hostile
- **Reason:** Removes kernel code-integrity protection. Every kernel anti-cheat refuses to start while any of these is active, and they are BCD changes, which iG Windows Tuner never makes. The health report flags them if they are on.
- **Sources:** <https://learn.microsoft.com/en-us/windows-hardware/drivers/install/the-testsigning-boot-configuration-option>

## Image File Execution Options edits on game executables (PerfOptions, Debugger)

- **Claim:** Forces high CPU or I/O priority for a game on every launch.
- **Category:** anti-cheat-hostile
- **Reason:** IFEO is a classic hijack location that Microsoft Defender and kernel anti-cheats watch; edits on game executables can be flagged. Raising a game above normal priority does not help when Windows already boosts the foreground window, and can starve audio and input threads.

## Registry cleaners

- **Claim:** Removes registry junk to speed Windows up.
- **Category:** unstable
- **Reason:** Leftover registry entries do not slow Windows down measurably, and automated deletion breaks applications and uninstallers. The iG Windows Tuner cleaner only deletes files from allow-listed cache folders.

## Blocking telemetry through the hosts file

- **Claim:** Stops Windows from sending data.
- **Category:** security-reducing
- **Reason:** Microsoft Defender detects hosts-file entries that block Microsoft endpoints as a settings modifier (HostsFileHijack), and the blocks break Windows Update, activation and Store downloads. iG Windows Tuner uses the documented diagnostic data policies instead.

## Cleaning the Prefetch folder

- **Claim:** Speeds up application launches.
- **Category:** placebo
- **Reason:** Windows uses the Prefetch traces to load applications faster and rebuilds them anyway, so deleting them only makes the next launches slower. The cleaner never touches %SystemRoot%\Prefetch.

## Deleting files inside WinSxS or %SystemRoot%\Installer by hand

- **Claim:** Frees many gigabytes.
- **Category:** unstable
- **Reason:** WinSxS uses hard links (its real size is much smaller than Explorer shows) and Installer holds the packages needed to repair, update and uninstall software. Manual deletion breaks servicing and uninstallers. The cleaner uses DISM component cleanup instead.
- **Sources:** <https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/clean-up-the-winsxs-folder>

## Disabling IPv6

- **Claim:** Lowers latency and fixes connection problems.
- **Category:** unstable
- **Reason:** Microsoft does not support disabling IPv6; components such as Teredo, Xbox networking and some Windows features expect it. When IPv6 causes a problem, Microsoft's guidance is to prefer IPv4 over IPv6 instead.
- **Sources:** <https://learn.microsoft.com/en-us/troubleshoot/windows-server/networking/configure-ipv6-in-windows>
