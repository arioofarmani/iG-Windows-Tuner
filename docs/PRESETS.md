## Competitive: Maximum performance, lowest latency

*Maximum performance and lowest latency: every Tier A item plus situational Tier B latency tweaks. Anti-cheat safe.*

The security baseline stays fully on: Defender, VBS/HVCI, ASR baseline, LSA protection, firewall. Nothing that anti-cheat needs is touched.
